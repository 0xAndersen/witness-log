# witness-log brand

**Mark:** a four-leaf Merkle tree in cyan wireframe; the root is amber,
ringed by a dashed circle — the witnessed head, seen by an independent
party. `logo-mark.svg` is the source; `logo-mark.png` (800 px) and
`logo-wordmark.png` are renders.

**Wordmark:** `witness-log` in JetBrains Mono Bold, the hyphen in cyan.

**Palette:** background `#0c0f1d` → `#070910` with a faint indigo glow
`#1b1540`; cyan `#5ee7ff` (structure, proofs); amber `#ffb347` (the
witnessed head, prompts); text `#e8eefc` / `#aeb8d6`; success `#6cf0b2`;
failure `#ff6b6b`.

**Type:** Space Grotesk (headlines), JetBrains Mono (code, numbers, labels).

**Texture, used lightly:** a perspective wireframe floor fading from
cyan to amber at the horizon, and faint scanlines. It is backdrop, never
the subject.

Social graphics are generated from an HTML template with Playwright; the
X launch set lives with the launch material, not in this repository.
