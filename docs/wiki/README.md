# docs/wiki

The source of the GitHub wiki (https://github.com/0xAndersen/witness-log/wiki).
Pages are plain Markdown with wiki-style links (`[Text](Page-Name)`), so
they render here on GitHub too. The `wiki` workflow publishes this
directory to the wiki automatically on every change to `docs/wiki/`
(after the wiki has been created once in the UI). Edit here, not in the
wiki UI: the UI copy is overwritten on the next sync.
