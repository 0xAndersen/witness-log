# Code of conduct

witness-log is built in public by people who may never meet: library
authors, witness operators, auditors, agent developers. The project only
works if they can disagree about technical questions and still trust each
other's good faith.

## Expected

- Argue about the work, not the person. Disagreement about a design, a
  finding or a verdict is welcome and is how this project gets better.
- Assume good intent, and say what you mean plainly.
- Credit others' findings and code.
- Report security problems privately, as `SECURITY.md` describes.

## Not acceptable

- Harassment, insults, or demeaning remarks about anyone's identity,
  background or ability.
- Personal attacks, threats, or encouraging others to do either.
- Publishing someone's private information without permission.
- Sustained disruption of issues, discussions or reviews.

## Scope and enforcement

This applies in every project space: issues, pull requests, discussions,
the wiki, and anywhere someone represents the project. Report a problem to
the maintainers through a private security advisory
(<https://github.com/0xAndersen/witness-log/security/advisories/new>) with
"conduct" in the title. Reports are kept confidential. Maintainers may
edit or remove content, and warn, suspend or ban a participant, in
proportion to what happened.
